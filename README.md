# FoodRescue

Good food deserves another chance.

FoodRescue is a full-stack platform that connects food providers
with individuals and organizations to rescue surplus food and
reduce food waste.

## Planned Features

- Provider, recipient, and admin accounts
- Surplus food listings
- Food search and filters
- Nearby food discovery
- Food claiming and pickup tracking
- Real-time notifications
- Provider verification
- Reviews and trust system
- AI-powered food matching
- Community impact statistics

## Planned Tech Stack

- React
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Socket.IO
- Cloudinary
- Leaflet / OpenStreetMap
- Groq AI
